# 教育培训（Education / Training）行业分析模板

## 适用范围与识别信号

适用于学校、职业教育、语言培训、职业资格、企业培训、在线课程、训练营和线下班级等以学习过程和学习结果为核心的业务。建议同时出现以下信号中的至少两类，才能采用本模板：学员/客户 ID、课程/班级/课次或课件 ID、报名/缴费/退费、排课与实际上课、学习时长、作业/考试成绩、结课/证书、满意度、续报或就业跟踪。

只有课程名称、销售额或报名人数时，使用通用模板；不能凭“完成率高”“通过率高”推断教学质量或学习效果。

## 业务链路与统计对象

```text
咨询/申请 → 录取/报名 → 缴费 → 开课/首次学习 → 出勤与学习活动
                                      → 作业/测验/考试 → 结课/证书
                                                           → 续报/转介绍/就业等后续结果
```

链路中的实体不同：一个学员可有多次报名，一个报名可包含多个课程或班级，一个课次可有多次签到/补签。先确定分析单位是学员、报名记录、课程、班级还是课次；不同实体不能直接混用分母。完成率和后续结果必须等观察窗结束，未成熟 cohort 单独标记。

## KPI 词典与必要条件

| 指标 | 推荐定义 | 至少需要 | 禁止推断 |
|---|---|---|---|
| 线索/申请量 | 窗口内去重的有效咨询或申请数 | 线索/申请 ID、来源、时间、有效性规则 | 表单提交数不一定是有效线索 |
| 报名转化率 | 完成报名的申请或合格线索数 / 对应分母 | 申请与报名 ID、资格规则、同一窗口 | 没有分母或资格规则不能计算 |
| 报名人数/报名记录数 | 去重学员数或报名记录数，必须注明实体 | 学员 ID、报名 ID、课程/班级 ID | 报名记录数不能当作学员人数 |
| 实收学费/缴费额 | 已收款金额，另列退款、应收和确认收入 | 支付/账单 ID、金额、收款与退款时间、币种 | 缴费流水不自动等于会计收入 |
| 退费率 | 完成退费的报名记录或金额 / 对应报名或实收分母 | 退费状态、报名/支付 ID、观察窗口 | 申请退费不等于已退费 |
| 开课率/首学率 | 已开课且在窗口内首次学习的报名数 / 应开课报名数 | 计划开课时间、实际学习事件、报名 ID | 没有计划集合不能算“按期开课” |
| 出勤率 | 学员—课次出勤数 / 应出勤的学员—课次数 | 排课、学员、签到状态、补签/请假规则 | 课次签到人数 / 学员数会混淆分母 |
| 出勤及时率 | 在规定时间窗内签到的应出勤记录占比 | 课次开始时间、签到时间、时限定义 | 没有时限不能判定迟到 |
| 学习活动率 | 在窗口内完成至少一项规定学习活动的学员数 / 进入观察窗的报名学员数 | 学习事件、活动定义、学员/报名 ID | 登录一次不必然等于有效学习 |
| 学习时长 | 学员有效学习时长的总量或中位数 | 开始/结束或平台有效时长、异常值规则 | 页面打开时长不等于有效学习时长 |
| 作业完成率 | 按期完成作业数或学员数 / 应提交作业数或学员数 | 作业、截止时间、提交状态、分母规则 | 提交但未达到要求不能直接算完成 |
| 评估参与率 | 有效提交考试/测验的学员数 / 应参加学员数 | 评估安排、学员 ID、有效尝试规则 | 参加一次不能代表掌握程度 |
| 通过率 | 达到已公布标准的有效尝试或学员数 / 有效评估分母 | 评分、通过阈值、评估版本、重考规则 | 不同难度/版本成绩不能直接比较 |
| 课程完成率 | 达到该版本结课条件的学员/报名数 / 观察窗内应完成分母 | 完成条件、课程版本、报名日期、成熟观察窗 | 未到结课期的报名不能计入分母 |
| 证书获得率 | 获得证书的合格学员数 / 满足证书资格的学员数 | 证书规则、资格和发证记录 | 结课不一定等于获得证书 |
| 学习增益 | 同一学员可比的后测分数 - 前测分数，报告分布与匹配率 | 同量表前后测、学员 ID、测试时间、缺失规则 | 不同试卷或不同量表分数相减 |
| 结课/完成时长 | 从报名或开课到满足完成条件的时长中位数/P90 | 起点、完成时间、时区、观察窗 | 只有月份不能声称天级时效 |
| 满意度/推荐意愿 | 按问卷定义的评分或推荐者比例，同时报告响应率 | 问卷版本、回答、发送对象、响应时间 | 低响应率调查不能代表全体学员 |
| 续报率 | 在规定窗口内再次报名的成熟学员数 / 有资格续报的学员数 | 原报名、后续报名、资格和窗口 | 只看总报名增长不能推断续报 |
| 学员后续结果率 | 完成约定就业、升学或技能应用结果的学员数 / 有效跟踪分母 | 结果定义、跟踪时间、联系方式和回应状态 | 未跟踪的学员不能当作未就业或未达成 |
| 席位利用率 | 按目标分别计算报名席位 / 可售席位或有效出勤席位 / 可用席位，不合并命名 | 班级容量版本、报名/出勤、窗口 | 报名人数高不等于产能或教学质量高 |
| 单学员成本 | 可归属成本 / 明确的学员或报名分母 | 教师、场地、平台、获客成本和归属规则 | 没有成本分摊不能计算成本 |
| 单学员贡献 | 按确认收入减可归属成本后的贡献 / 明确的学员或报名分母 | 收入、成本、学员/报名 ID 和归属规则 | 缴费额不能直接当贡献 |

“通过”“完成”“有效学习”“学员结果”必须引用课程版本、评估版本和观察窗。行业目标不预置在模板中，目标应来自用户确认的教学要求、合同 SLA 或历史基线。

## 必须通过的数据门禁

1. **学员与报名关系**：学员 ID、报名 ID、课程/班级/课次层级可关联；同一学员多次报名必须保留尝试序号。
2. **计划与事件时间**：计划开课、课次开始、签到、学习、考试、结课和退费均使用事件时间，明确时区和补录规则。
3. **完成条件版本**：记录课程大纲、结课条件、证书资格和成绩阈值的版本；版本变更前后分段比较。
4. **分母与观察窗**：出勤、完成、续报和后续结果必须定义应参加/应完成集合及成熟窗口；末期 cohort 进入右删失区。
5. **成绩可比性**：前后测或班级比较需确认量表、难度、评分方式和重考处理一致；不能用平均分替代学习增益。
6. **缴费退费对账**：支付、退款、优惠、分期和会计确认周期可对账；缴费额、应收和收入分开命名。
7. **出勤与活动去重**：签到、补签、请假、旁听和重复学习事件有明确有效规则；不以日志行数代替学员—课次记录。
8. **问卷代表性与隐私**：报告响应率、匿名/脱敏规则和小样本阈值；低响应率满意度不外推全体。
9. **结果跟踪完整性**：就业、升学或技能应用结果说明跟踪时点、回应率和缺失状态；缺失不是失败。
10. **成本归属**：教师、场地、平台、教材和获客成本有科目、窗口与分摊规则；否则只报告收入或运营量。

## 典型分析主题与流程

### 1. 招生与缴费漏斗

先定义有效线索、合格申请、报名和实收的实体与时间；按来源、课程、地区或班型拆解各阶段转化和流失量。报名人数、报名记录、缴费笔数分别报告，不能混成一个“招生转化率”。没有资格或计划集合时降级为事件量描述。

### 2. 开课 cohort 的出勤、活动与完成

按开课月或报名月建立 cohort，观察首学、出勤、活动、作业和结课随时间的变化；对不同课程长度使用相对课次/学习周比较。未到完成窗口的 cohort 不进入完成率排名，缺失签到先进入质量门禁。

### 3. 评估与学习增益

核对前后测匹配、考试版本和评分尺度，报告参与率、分数分布、通过率及匹配学员的增益。班级或教师差异先控制课程、学员基础和样本量；没有随机分班或可比对照时，写成关联和待验证教学机制。

### 4. 课程、班级与教师运营诊断

同时看规模（报名/席位）、过程（出勤/活动/作业）和结果（完成/通过/满意度），报告分母、置信区间或样本量。小班极端值不直接排名；教师评价不与班级构成混为因果结论。

### 5. 退费、流失与续报

区分未开课退费、开课后退课、未完成和自然结课；按报名阶段、课程、价格方案和学员基础分层，比较成熟 cohort 的退费和续报。没有退费原因、跟踪窗口或成熟分母时，只报告状态和时间，不写原因。

### 6. 满意度与后续结果

报告问卷分数、响应率、课程阶段和结果跟踪覆盖；将满意度与出勤、学习活动和完成做关联检查。就业或技能应用结论只适用于实际回应且定义明确的分母，不能把未回应者当作失败或成功。

### 7. 单位经济与排课容量

在同一课程、班级和周期内对齐实收、退费、教师/场地/平台成本与席位容量，分析单位学员成本、班级盈亏和容量利用。缺少可归属成本或容量版本时，只做收款、人数和排课量描述，不补行业价格。

## 常见数据陷阱

1. **报名 vs 入学 vs 到课**：报名是行为，入学是注册，到课是出勤，三个分母差异巨大；
2. **退费率分母**：跨期退费与当期报名混算会失真；
3. **完课率口径**：完课是完成全部课时 / 完成考试 / 拿到证书，三者不同；
4. **出勤率统计**：直播出勤 vs 录播出勤不同；点播回放也会被算"出勤"；
5. **学习时长污染**：后台学习时长 / 心跳时长可能包含未观看；
6. **学员去重**：同一学员跨学科 / 跨班 / 跨课程重复注册；
7. **退费政策切换**：退费政策变更前后数据不可合并；
8. **成绩与考试口径**：补考 / 重考 / 模拟考混入会过估通过率；
9. **续报率窗口**：续报窗口期不同（学期 / 年 / 课程），不可比；
10. **招生季节性**：寒暑假 / 春秋季招生节奏不同，跨期对比必须挂周期；
11. **班级容量差异**：小班 vs 大班 vs 1v1 完课率与续报率不可比；
12. **跨地区政策**：K12 双减 / 职业教育 / 语言培训 政策不同，不可比；
13. **教师/课程版本**：同一课程不同老师 / 不同版本不可合并；
14. **续费 vs 复购**：续费是按周期续，复购是新购，二者含义不同；
15. **课后效果追踪**：就业率 / 升学率追踪窗口 > 12 个月时数据未成熟；
16. **销售线索归属**：试听课 vs 体验课 vs 测试 线索归属不一致。

## 行业叙事语言

- “该开课 cohort 在第 X 周的出勤率相对同课程历史基线偏离 Y 个百分点”；
- “完成率仅在观察窗结束的报名中计算，末期 cohort 仍存在右删失”；
- “A 班通过率较高，但学员基础、评估版本和样本量尚未对齐，不能归因于教师”；
- “按已回应学员计算的满意度为 X，响应率为 Y%，外推范围有限”；
- “缴费额为现金流观测，是否为确认收入取决于财务口径”；
- “出勤下降与作业延迟同步出现，是待验证机制，需要课次和补录日志”；
- “若补充前后测、课程版本和成熟 cohort，可验证学习增益与完成差异”。

避免使用“课程有效”“老师导致成绩提升”“高通过率代表教学质量”“未就业”“学员不努力”等超出字段和对照证据的判断。

## 图表优先级

1. 招生/缴费分子分母漏斗；
2. cohort 出勤、活动和完成率热力图或曲线；
3. 课次出勤与作业延迟的时间序列；
4. 班级/课程规模 × 过程/结果指标的散点或分面图；
5. 前后测匹配学员的分数分布与增益区间；
6. 退费阶段和原因的可对账条形/帕累托图；
7. 席位、教师投入、单位成本与结果的成本—服务散点。

每张图写清分析实体、课程/评估版本、观察窗、分母、成熟规则、问卷响应率和排除项；缺少这些条件时不画排名或因果图。

## 输出与降级

分析计划至少输出：`business_decision`、`metric_dictionary`、`learner_grain`、`course_version`、`event_time_policy`、`observation_window`、`baseline`、`evidence_contract`、`selected_methods`、`selected_charts`、`missing_data` 和 `max_claim_level`。

- 没有学员/报名 ID：只做汇总人数或收款趋势，不能去重、做 cohort 或续报；
- 没有计划和事件时间：不算按期开课、出勤及时率或完成时长；
- 没有完成条件和成熟观察窗：不算课程完成率或证书获得率；
- 没有可比前后测：不算学习增益，只报告成绩分布；
- 没有应出勤集合：不算出勤率，只报告签到记录；
- 没有退费/支付对账：不把收款当收入，不计算净学费；
- 没有问卷分母与响应率：不外推满意度；
- 没有结果跟踪：不推断就业、升学或技能应用；
- 没有成本和容量：不计算利润、单学员成本或利用率；
- 课程/评估版本不一致：分版本报告，不合并排名。

**最低可分析标准**：至少有明确的分析实体（学员、报名或课程）、一个时间字段，以及报名、出勤、学习或评估中的一项观测量；这只能支持描述性分析，不自动支持教学效果或商业因果结论。
