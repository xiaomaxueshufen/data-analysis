# 互联网 SaaS 行业分析模板

## 适用范围与识别信号

适用于 B2B SaaS、B2C 订阅、企业软件、云服务和按席位/用量计费的数字产品。建议至少同时出现以下两类信号：客户/组织 ID、订阅或合同 ID、套餐/席位/用量、账单/支付/退款、登录或核心功能事件、试用/激活、取消/欠费、支持工单或获客成本。

仅有月度收入或登录次数时使用通用模板；不能凭收入趋势补出 MRR、流失、LTV 或产品价值。

## 业务链路与统计对象

```text
获客/注册 → 试用或签约 → 激活 → 核心功能使用 → 续费/扩展
                                         → 降级/暂停/取消/欠费
财务链路：合同/订阅 → 账单 → 收款/退款 → 确认收入
```

先确定客户（logo/组织）、用户席位、订阅、合同和账单的关系。一个组织可有多个工作区和席位，一个订阅可有多次升降级；MRR 以订阅快照或合同月化价值为单位，不能把账单行、支付流水或登录用户直接当客户。

## KPI 词典与必要条件

| 指标 | 推荐定义 | 至少需要 | 禁止推断 |
|---|---|---|---|
| MRR | 期末有效订阅的月化经常性价值；明确折扣、年付和用量计费规则 | 订阅/合同 ID、状态、月化金额、有效日期 | 一次性实施费、咨询费不能直接计入 MRR |
| ARR | 按确认口径的 MRR × 12 或年化合同经常性价值 | MRR/合同快照和年化规则 | 月收入乘 12 不必然是 ARR |
| 新增/扩展/收缩/流失 MRR | 相邻有效快照中由新签、升配、降配、取消造成的 MRR 变化 | 客户/订阅 ID、前后快照、变更类型和生效时间 | 只有总收入不能拆解 MRR 变动 |
| 净新增 MRR | 新增 + 扩展 - 收缩 - 流失（按同一口径） | 上述四项可对账数据 | 未对账的收入变化不能称净新增 |
| 收入留存率（NRR） | 期初客户 cohort 的期末 MRR / 期初 MRR，通常不含新客户 | 期初 cohort、前后 MRR、扩展/收缩/流失 | 把新客户收入混入 NRR |
| 客户数流失率（Logo churn） | 期内失效客户数 / 期初有效客户数 | 客户状态、起止时间、流失定义 | 试用未转付费与付费客户取消不能混为一类 |
| 收入流失率 | 流失 MRR / 期初 MRR，注明主动/被动欠费 | 期初 MRR、流失分类和时间 | 没有成熟观察窗不能比较流失 |
| ARPU/ARPA | MRR / 期末付费用户数或客户数，必须说明实体 | MRR、用户/客户去重 | 席位数、账号数不能替代客户数 |
| CAC | 获客相关销售和营销成本 / 新增付费客户数 | 成本科目、客户首付、归属窗口 | 只有广告花费不能代表 CAC |
| LTV | 基于成熟留存 cohort 的累计毛利或收入价值 | 客户级收入、成本、留存窗口和毛利规则 | 用 1/流失率直接补出 LTV |
| CAC 回收期 | CAC / 每月客户毛利（按确认的月化规则） | CAC、客户毛利、月化收入和成本 | 没有毛利不能计算回收期 |
| 注册/试用转化率 | 完成付费的注册/试用实体 / 对应进入分母的注册/试用实体 | 注册、试用、付费 ID、窗口和成熟规则 | 没有进入分母集合不能计算 |
| 激活率 | 完成已定义关键行为的注册/试用用户 / 进入激活观察窗的用户 | 行为事件、激活定义、用户 ID、观察窗 | 首次登录不能自动算激活 |
| 活跃率（DAU/MAU 等） | 发生已定义有效活动的去重用户数 / 对应周期活跃用户数 | 用户事件、有效活动定义、窗口 | 登录或心跳日志不能默认是有效使用 |
| 功能采用率 | 在窗口内使用指定功能的用户/客户 / 有资格使用的活跃用户/客户 | 功能事件、资格集合、去重规则 | 功能曝光不等于使用 |
| 用量/席位利用率 | 实际用量或活跃席位 / 套餐包含量或已购席位 | 用量、席位和套餐版本 | 没有上限/购买量不能算利用率 |
| NPS/CSAT | 按问卷版本计算推荐意愿或满意度，同时报告响应率 | 问卷版本、回答、发送对象、客户 ID | 低响应率问卷不能代表全体客户 |
| 支持工单率 | 窗口内产生有效支持工单的客户数或工单数 / 约定客户或用户分母 | 工单 ID、工单类型、客户/用户 ID、去重规则 | 工单数不能直接当作客户数或产品缺陷数 |
| 扩展机会率 | 满足事先定义的用量、席位或意向条件的客户占比 | 动作前信号、资格规则、客户快照 | 相关信号不等于一定会升级 |
| 硬件/云服务毛利率 | 按收入、基础设施、服务和分摊规则计算 | 收入确认、成本科目、分摊规则 | 没有成本不能套行业毛利率 |

目标值必须来自用户确认的合同、经营目标或历史基线。MRR、账单收入、现金收款和确认收入分开命名，不能互换。

## 必须通过的数据门禁

1. **订阅快照完整性**：每个订阅/客户有状态、金额、套餐、席位和生效/失效时间；状态变更可排序。
2. **客户层级去重**：账号、工作区和组织的映射可追溯；报告同时注明用户级和客户级分母。
3. **经常性收入口径**：年付月化、折扣、税、一次性费用、用量费用和退款规则由合同/财务确认。
4. **流失与观察窗**：区分主动取消、欠费、试用到期和合同到期，设置宽限期和成熟窗口。
5. **计费与产品时间对齐**：订阅、账单、支付、退款和确认收入按统一时区与财务周期对齐。
6. **行为事件质量**：关键功能事件有用户/客户 ID、事件时间、版本和去重规则；埋点变更分段比较。
7. **成本和获客归属**：销售、营销、云资源、支持等成本有科目、窗口和客户/产品归属；否则不算 LTV/CAC 或毛利。
8. **实验和归因边界**：有处理/对照、分流单位和处理前窗口才做增量；普通渠道归因只作模型结果。
9. **问卷与工单代表性**：披露响应率、抽样对象和重复工单规则；小样本不排名。
10. **分组可加总**：套餐、渠道、行业和规模分组的分子分母可对账总量，不平均分组率。

## 典型分析主题与流程

### 1. MRR 变化与收入质量

先从有效订阅快照对账期初、期末 MRR，再拆新增、扩展、收缩和流失；同时分开一次性收入、退款和现金。若只有总账收入，降级为收入趋势，不声称订阅增长或负流失。

### 2. 注册—激活—付费漏斗

按用户或客户定义“注册、进入试用、激活、付费”，报告每阶段分母、成熟观察窗和分流去重。激活行为须在分析前确定，不能用事后付费结果定义激活。

### 3. cohort 留存与流失

按注册、首次付费或合同开始建立 cohort，观察活跃、续费、客户数流失和收入留存；对不同合同期限、套餐和客户规模分层。末期 cohort 未到续费期时不与成熟 cohort 排名。

### 4. 功能使用与客户价值

把功能采用、用量、席位和支持工单与留存/扩展做时间对齐的关联分析；控制客户规模、套餐和使用资格。没有处理对照时，只写同步或候选信号，不写功能导致留存。

### 5. 获客渠道与单位经济

对齐渠道成本、注册/试用、付费、成熟留存和客户毛利，报告 CAC、回收期和按 cohort 计算的价值。没有完整成本或成熟留存时，降级为渠道规模和转化，不用行业基准补 LTV。

### 6. 套餐、定价与扩展机会

比较套餐选择、升降级、用量接近上限和客户规模；调价前后需有可比基线或实验。扩展机会只输出满足规则的客户名单/比例，不能把潜力写成确定收入。

### 7. 服务质量与客户反馈

将工单量、首次响应/解决时长、NPS/CSAT 与留存和扩展按客户粒度对齐，保留响应率与工单去重。相关关系用于确定排查顺序，责任和因果需要事件时间与对照。

## 常见数据陷阱

1. **MRR ≠ 月度收入**：MRR 是月末有效订阅月化价值；月度收入是现金流水或确认收入；
2. **账单 vs 确认收入**：现金收款 ≠ 应收 ≠ 确认收入，必须按财务口径；
3. **ARR = MRR × 12**：年付月化 × 12 才是 ARR；月度收入 × 12 不等于 ARR；
4. **新签 vs 扩展**：新签是新订阅，扩展是既有客户升配或加席位；
5. **流失定义**：主动取消 / 欠费 / 试用到期 / 合同到期 是不同流失原因，分别报；
6. **流失观察窗**：未到续费周期的合同不能算流失；
7. **CAC 归属**：CAC 应含销售成本 / 营销成本 / 获客工具 / 返点；只用广告花费会低估；
8. **LTV 观察窗**：未到成熟窗口时 LTV 上界代替；
9. **客户 vs 用户**：一个客户（logo）可有多个工作区和席位；客户级 vs 用户级不能合并；
10. **试用期客户**：试用转付费与续约期客户流失率不可比；
11. **扩展机会率 ≠ 扩展概率**：满足规则不代表会升配，必须有信号；
12. **年付 vs 月付折扣**：折扣口径必须显式，否则 MRR 会被低估；
13. **席位利用率**：实际活跃席位 / 已购席位 vs 实际活跃席位 / 套餐上限；
14. **功能采用 vs 功能曝光**：曝光不等于使用；
15. **NPS / CSAT 响应率**：低响应率样本不可代表全体客户；
16. **工单数 vs 客户数**：工单数不等于客户数；
17. **COGS（履约 / 云 / 支持）**：缺 COGS 不算毛利率，不算回收期；
18. **续约率 vs 续费率**：续约率按客户数，续费率按金额；分母不同。

## 行业叙事语言

- “期末 MRR 相对上期变化 X，其中新增/扩展/收缩/流失各贡献 Y，已完成订阅快照对账”；
- “该 cohort 在第 X 月的客户留存为 Y%，末期 cohort 尚未成熟”；
- “使用某功能与较高留存同步出现，是待验证信号，不能写成功能造成留存”；
- “渠道 CAC 按当前成本归属为 X，LTV 尚因观察窗不足未计算”；
- “问卷满意度为 X，响应率为 Y%，结论只适用于已回应客户”；
- “按归因模型记录了 X 元收入，未设置对照，不能称为增量”；
- “补充订阅快照、成本归属和成熟留存后，可验证单位经济与扩展价值”。

避免使用“负流失已证明”“功能带来续费”“渠道质量差”“调价一定提升收入”等没有可比对照或完整快照的判断。

## 图表优先级

1. MRR 期初到期末的对账瀑布；
2. 注册/试用—激活—付费的分母明确漏斗；
3. cohort 客户留存和收入留存热力图；
4. 功能采用 × 留存/扩展的分层散点；
5. 渠道成本、转化和成熟价值的分面图；
6. 套餐升降级和用量接近上限的分布；
7. 工单/满意度与留存的时间序列或关联图。

每张图注明客户/用户实体、收入口径、合同/产品版本、成熟窗口、分母和是否为归因或对照结果；条件不足时不画因果图。

## 输出与降级

分析计划至少输出：`business_decision`、`metric_dictionary`、`customer_grain`、`subscription_policy`、`event_time_policy`、`observation_window`、`baseline`、`attribution_window`、`evidence_contract`、`selected_methods`、`selected_charts`、`missing_data` 和 `max_claim_level`。

- 没有订阅/合同快照：不拆 MRR、留存或流失，只做收入趋势；
- 没有客户/订阅 ID：不去重客户，不做 cohort、ARPA 或 NRR；
- 没有状态时间和成熟窗口：不计算流失、续费和回收期；
- 没有行为事件：不分析激活、功能采用或活跃率；
- 没有成本：不计算 CAC、LTV、回收期或毛利；
- 没有归因窗口/对照：只报告渠道或模型归因，不写增量因果；
- 没有问卷分母/响应率：不外推 NPS 或 CSAT；
- 版本或计费口径变化：分段报告，不合并趋势或排名。

**最低可分析标准**：至少有客户或订阅实体、经常性金额（或明确收入字段）和有效日期；这只能支持收入/订阅描述，不自动支持留存、产品因果或单位经济。
