# 通用行业分析模板

## 适用范围

当行业无法从用户问题、字段和数据字典可靠识别，或用户明确要求不套行业口径时使用。模板提供通用决策框架，**不**为字段补充业务含义——任何"可能是 GMV / DAU / 留存"的字段都要回到用户侧确认，不在分析层硬猜。

## 优先确认（先做且必须做完）

| 问题 | 回答要点 | 没回答前能不能继续 |
|---|---|---|
| 业务对象是什么 | 用户、订单、设备、门店、账户、合同还是其他实体；明确去重键 | 不能——所有比率的分母都依赖 |
| 一行代表什么 | 是事件、快照、日还是宽表；同一实体是否有重复 | 不能——总量对账直接受影响 |
| 主指标公式 | 分子、分母、单位和完成时点 | 不能——所有衍生指标都基于此 |
| 观察窗口与基线 | 比较的是上周/上月/同期/去年；窗口不切直接报告跨期漂移 | 不能——任何时间维解读都依赖基线 |
| 决策维度 | 哪个维度驱动决策；分组是否能加总 | 可继续，但结论要标"待分组确认" |

## 通用主题

1. **时间趋势与基线偏离**：用同 weekday 中位数或用户提供的基线，写绝对差、相对差、稳健 z，不写"涨跌幅"；
2. **漏斗与分子分母对账**：每一步明确分子是什么、分母是什么、有没有交叉过滤；
3. **组间规模/效率/贡献拆解**：先看规模加权贡献，再看相对降幅；不能只看降幅不看规模；
4. **数据质量门禁**：口径切换点、版本上线日、活动期作为独立字段列出，不在分析中"自动处理"；
5. **后续实验设计**：结论若需要进一步验证，列出实验或补数设计。

## 业务链路占位符

通用模板不画业务链路图。下列填空清单必须由用户填完后才进入业务分析：

```
[业务对象] ──[动作 1]──▶ [动作 2] ──▶ [终止态]
  │
  └── 财务/事件链路：[记账]──▶ [结清/对账]
```

## 常用比率（仅作为通用定义，不绑死业务）

| 比率 | 通用公式 | 必要条件 |
|---|---|---|
| 转化率 | 完成目标事件实体数 / 进入实体数 | 进入分母与目标实体可对齐 |
| 留存率 | 第 N 期活跃实体数 / 第 0 期实体数 | 实体可去重，期定义明确 |
| 流失率 | 期内失效实体数 / 期初实体数 | 失效定义、宽限期、观察窗 |
| 单价 | 总金额 / 去重实体数 | 金额字段、单位、去重键 |
| 集中度 | Top N 实体合计 / 总计 | Top N 的实体可识别 |

## 数据陷阱清单（任何行业都先核一遍）

1. **时区**：跨地域数据是否已统一到同一时区；未统一会导致"今天凌晨"和"今天下午"被算成不同日；
2. **去重**：同一实体的多条记录在分子分母里各算一次还是多次；用户 ID 跨设备是否打通；
3. **空值/未知**：`NULL`、`(not set)`、`unknown`、`空字符串`是否被当 0 计入；通常应该剔除或单独披露；
4. **窗口错位**：埋点日期、订单日期、支付日期、确认收入日期在不同口径下不可互换；
5. **极端值**：金额、时长类长尾是否被 winsorize；不 winsorize 的均值会被 1% 头部拉偏；
6. **多重比较**：同时检验多个分群/指标时未做 FDR/Holm 校正，p 值不可信；
7. **归因误用**：把归因份额当成因果增量，没有实验就不写"由 X 导致"；
8. **样本量**：分群样本 < 30 时不排名、不算显著性，只描述；
9. **版本切换**：埋点版本、计费规则、活动规则变更前后是否分段；不分段会出现"伪断点"；
10. **左右删失**：留留存/生存分析必须有删失字段或明示窗口，否则会高估生存率。

## 叙事规则

- 先写"数据中看到什么"，再写"与什么候选解释一致"，最后写"还需要什么才能验证"；
- 没有用户确认的行业基准不写入数字结论；
- 没有处理与对照不写因果；
- 数字必须能溯源到具体行/字段，evidence_ids 与 limitations 列表必须完整。

## 图表优先级

时间序列、分子分母漏斗、可加总贡献条形图、字段质量表。

## 输出与降级

分析计划至少输出：`business_object`、`metric_formula`、`observation_window`、`baseline`、`evidence_contract`、`selected_methods`、`selected_charts`、`missing_data`、`max_claim_level`、`limits_filled_by_user`。

- 不填业务对象：只输出数据质量表，不做任何业务结论；
- 不填基线：只做横截面分布对比，不写时间异常；
- 没有去重键：所有去重指标降级为行级计数；
- 数据存在口径切换点：分段报告，不合并趋势或排名。

**最低可分析标准**：至少有可去重的实体字段与时间字段。这只能支持时间趋势与简单分群描述，不自动支持因果或价值结论。
