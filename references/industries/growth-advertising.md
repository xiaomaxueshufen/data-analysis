# 互联网增长与广告投放行业分析模板

## 适用范围与识别信号

适用于做用户增长、效果广告投放、品牌投放、媒介采买、流量采买与增长运营（SEO / 内容 / 推送 / 推荐 / 裂变）的互联网团队。建议至少同时出现以下两类信号：广告计划 ID / 创意 ID、曝光/点击/点击率、消耗/订单/GMV、获客/激活/付费事件、漏斗事件、广告 ROAS / CAC / LTV、归因窗口、归因模型、投放渠道/媒介/广告位/设备与素材。

仅有广告消耗而无回传转化、不接 ROI 接口的数据无法支持效果分析；只有曝光无后续事件不支持任何"效果"判断。

## 业务链路与统计对象

```text
曝光 → 点击 → 落地页 → 注册/登录 → 激活 → 付费 → 留存/复购
广告链路：计划 → 创意 → 媒介/广告位 → 用户 → 转化事件
归因链路：曝光/点击 → 归因模型 → 转化认领 → 价值分配
```

先确定：
- 投放主体（计划/创意/广告组/账户）；
- 触达主体（用户 ID / 设备 ID / 账号）；
- 转化主体（订单 ID / 付费事件 ID / 业务目标事件）；
- 归因窗口（点击归因 vs 曝光归因、窗口天数、跨设备规则）；
- 成本归属（消耗、返点、退款、刷量扣减）。

一个计划可对多个创意，一个用户可被多个计划触达多次。**ROAS / CAC 必须挂在归因模型上**，模型不同数值可差 2-3 倍。

## KPI 词典与必要条件

| 指标 | 推荐定义 | 至少需要 | 禁止推断 |
|---|---|---|---|
| 消耗（Cost / Spend） | 广告平台账单消耗，注明是否含返点/服务费 | 广告计划 ID、日期、消耗金额 | 用结算货币 vs 投放货币混算 |
| 曝光（Impression） | 广告位返回的有效曝光 | 计划 ID、日期、曝光量 | 素材加载失败计为有效曝光 |
| 点击（Click） | 触发落地的有效点击 | 计划 ID、日期、点击量 | 误点/重复点击未去重 |
| CTR | 点击 / 曝光 | 曝光、点击 | 时段维度 CTR 与日维度 CTR 不可加 |
| CVR | 转化 / 点击 | 点击、转化 | 末次归因 CVR 与 multi-touch CVR 不同 |
| CPM | 消耗 / 曝光 × 1000 | 消耗、曝光 | 平台定义差异（CPM vs oCPM） |
| CPC | 消耗 / 点击 | 消耗、点击 | 智能出价下 CPC 不可拆 |
| CPA / CAC | 消耗 / 新增付费用户 | 消耗、付费用户 ID | "激活"≠"付费用户" |
| ROAS | 归因收入 / 消耗 | 消耗、归因收入 | 跨平台 ROAS 不可直接加总 |
| ROI / 净 ROI | (收入 - 成本 - 履约) / 成本 | 收入、成本、履约成本 | 只算收入不算履约 |
| 留存 D7 / D30 | 第 N 日活跃 / 第 0 日新增 | 实体 ID、活跃事件 | 把"激活"等同于"留存" |
| LTV | 累计毛利率 / 累计收入 | 客户 ID、毛利规则、成熟窗口 | 1/流失率直接算 LTV |
| 新增用户数 | 期内首次出现的实体数 | 实体 ID、首次事件时间 | 去重错误导致双计 |
| 召回率 / 重定向触达 | 历史用户中再次被触达的比例 | 用户 ID、广告受众规则 | 推送 + 短信 + 信息流混算 |
| 频次（Frequency） | 总曝光 / 去重用户 | 曝光、去重用户 | 按"次数"统计不区分触达 |
| eCPM / eCPC / eCPA | 实付 / 计量 | 平台实付数据 | 与平台结算口径不同 |
| 创意 CTR / CVR | 单创意的 CTR / CVR | 创意 ID、事件 | 创意轮换周期内合并计算 |

目标值来自投放预算约束与历史基线，不与不同时期、不同平台、不同窗口的基线比。

## 必须通过的数据门禁

1. **消耗与曝光对账**：曝光量级与媒体方报告差 ≤ 10%；否则归因无法解释；
2. **点击与曝光时序**：点击时间必须晚于曝光时间，否则为异常或数据回写；
3. **用户去重**：跨设备、跨账号是否打通；未打通时所有去重指标都是过估；
4. **归因模型声明**：每个渠道/平台的归因窗口与模型必须显式注明；
5. **新增口径**：首次出现日期的定义要统一（首次事件 / 首次注册 / 首次付费），不能换口径；
6. **退量与退款**：广告退量、用户退款必须反映到消耗与收入，不与"原数"相比；
7. **刷量识别**：可识别无效曝光/异常点击；缺失则所有比率都是乐观的；
8. **跨平台拼算**：不同平台归因口径不同，禁止直接加总，必须按"对账后口径"汇总；
9. **活动/调价**：促销期、品牌大投放日单独标注，不与常规日合并；
10. **成本归属**：消耗归属按日、按计划；缺失归属就不算 ROAS / ROI / CAC。

## 典型分析主题与流程

### 1. 渠道 ROAS / CAC 与增量

按渠道 × 计划看消耗、归因收入、新增用户、首次付费用户，再算 ROAS / CAC / 回收期。**不要**直接报"综合 ROAS = X"——所有平台口径不同，必须按归因模型标注。同时给出"按 last_touch / linear / shapley 的 ROAS 区间"，让决策者看到不同口径下的差异。

### 2. 素材与创意层

按计划 × 创意看 CTR / CVR / 创意疲劳（连续 3 天 CTR 下降）。衰减要写绝对量（如 CTR 从 4.2% 跌到 2.1%），不要写"显著下降"。

### 3. 受众与人群分层

按人群标签（新客 / 召回 / 高价值 / 沉默）看投放回报。注意召回受众的转化口径与新客不同，不能直接做"召回 vs 新客 ROAS"对比——分母不同。

### 4. 频次与触达上限

按频次分布看曝光集中度。当 Top 5% 用户贡献 > 30% 曝光时，已接近"老客反复曝光"，效率正在坍塌。

### 5. 漏斗与落地页

落地页 → 注册 → 激活 → 付费 的每一步转化与流失定位。用 funnel_rates 与 ratio_decomp 拆步骤。

### 6. 增量识别

明确区分"归因下的转化"和"由广告带来的增量转化"。没有 geo holdout / PSA / 平台 conversion lift 实验，只能写归因，不写增量。

### 7. 增长效率指标

CAC 回收期、获客投资回报率、获客 ROI 月度趋势、首次付费用户的 LTV 上界（成熟窗口未到时写 LTV）。

## 行业叙事语言

- "按 last_touch 归因，渠道 A 的 ROAS 为 3.2，linear 模型下为 2.6，shapley 为 2.8"——必须报区间；
- "CAC 为 X 元，按当前回收期 Y 个月"——必须挂 cohort 与窗口；
- "曝光量较上周下降 11.6%，点击率同步下降 4.3 个百分点"——双口径并报；
- "新客 vs 召回 ROAS 不可直接对比，分母口径不同"；
- "广告带来的增量未验证，本报告为归因结果，不称因果"。

避免使用"渠道 ROAS 最高""创意已疲劳""调高出价能带来更多收入"等无对照或无成熟窗口的判断。

## 常见数据陷阱

1. **跨平台 ROAS 误加总**：抖音的"转化"≠快手的"转化"≠广点通的"转化"。必须按归因窗口与事件口径分层加总；
2. **last_touch 偏好**：last_touch 模型下品牌词搜索、信息流末次曝光天然占便宜，单独排名会误导；
3. **激活 ≠ 付费**：用户激活后未付费的群体不应算在 CAC 的分母中；
4. **频次过载**：高频曝光下的 CTR 上升是"已触达高响应人群"的衰减样本，不应解读为"投放效率变好"；
5. **归因窗口不一致**：click 7d vs click 1d vs click 30d 的归因份额可差 2-3 倍，结论必须挂窗口；
7. **刷量与异常点击**：未做异常点击过滤的 ROI 是乐观的，必须在结论中披露过滤比例；
8. **退款回写延迟**：消费 ≥ 7 天才有退款回写的行业（电商/订阅），近期 ROI 会被乐观；
10. **沉默召回 vs 新客**：召回人群已经过完整漏斗，ROAS 偏低不一定"渠道无效"，可能是人群定义错了。

## 图表优先级

1. 渠道 × 模型的 ROAS 区间热力图；
2. 计划 × 创意的 CTR / CVR 散点（带创意疲劳窗口）；
3. 受众分层（人群 × 渠道）的 ROAS 条形图；
4. 频次分布 + Top 触达集中度；
5. 落地页漏斗步骤分子分母对账；
6. CAC 回收期 cohort 曲线；
7. 曝光/点击/转化事件的时间对齐与异常检测。

每张图必须挂归因模型、窗口、消耗/转化口径与证据链。

## 输出与降级

分析计划至少输出：`business_decision`、`channels`、`attribution_model`、`attribution_window`、`metric_dictionary`、`audience_definition`、`frequency_policy`、`incremental_design`、`evidence_contract`、`selected_methods`、`selected_charts`、`missing_data`、`max_claim_level`。

- 没有归因模型声明：只报消耗/曝光/点击与下游漏斗，不报 ROAS；
- 没有成本归属：不报 CAC / ROI，只报转化率与漏斗；
- 没有跨设备打通：所有去重数字加"按当前实体统计"注释；
- 没有成熟留存窗口：不报 LTV，只报"成熟窗口待观察"；
- 跨平台口径不可对齐：按平台分面展示，不跨平台加总；
- 没有增量识别设计：所有"效果"判定为 L1，禁止写"由广告带来"。

**最低可分析标准**：至少有广告计划 ID、消耗、曝光、点击与转化事件；这只能支持点击率 / 转化率 / ROAS 描述，不支持"增量"或 LTV。
