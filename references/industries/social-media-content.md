# 自媒体与内容创作（Social Media / Content Creation）行业分析模板

## 适用范围与识别信号

适用于公众号、短视频、直播、播客、图文社区、知识内容和个人/机构账号等以内容生产、分发和受众经营为核心的业务。建议同时出现以下信号中的至少两类，才能采用本模板：内容或作品 ID、账号/作者 ID、发布时间、曝光/触达/播放、观看时长或完播、点赞评论分享收藏、关注/取关、外链点击、线索/订单或平台结算收入。

“播放”“观看”“触达”“互动”是平台定义的观测量，不能跨平台直接当作同一指标。若数据只有内容标题或发布量，使用通用模板，不推断内容效果。

## 业务链路与统计对象

```text
选题/制作 → 发布 → 分发与曝光 → 播放/阅读 → 互动 → 关注/订阅
                                      → 外链点击/线索/订单/平台结算
```

这条链路不是天然漏斗：平台可能重复曝光同一用户，用户也可能跨天、跨内容完成互动或转化。只有同一内容或用户的事件可关联、去重规则和归因窗口明确时，才计算阶段转化；否则分别报告各指标的覆盖和分布。

分析前先确认三种粒度：内容（content）、账号/作者（account/creator）和用户（viewer/follower）。内容级平台汇总不能还原用户级留存；账号级收入不能直接分摊到单条内容。

## KPI 词典与必要条件

| 指标 | 推荐定义 | 至少需要 | 禁止推断 |
|---|---|---|---|
| 发布量 | 窗口内去重发布的内容数 | `content_id`、发布时间、发布状态 | 草稿或重复抓取行不能计为发布 |
| 曝光量/展示次数 | 平台记录的内容展示次数 | 内容 ID、展示事件或平台汇总、时间窗口 | 展示次数不是人数；不能称为触达用户 |
| 触达人数 | 看到内容的去重用户数 | 用户级触达 ID 或平台明确的 reach 字段 | 用曝光量代替人数 |
| 播放/阅读量 | 按平台规则记录的有效播放或阅读次数 | 平台定义、内容 ID、时间窗口 | 不同平台或不同起播门槛的播放不能直接合并 |
| 播放率/阅读率 | 播放或阅读量 / 曝光量；必须注明平台口径 | 曝光量、播放/阅读量、相同窗口 | 没有共同分母时不比较平台间“转化” |
| 平均观看时长 | 有效播放的总观看秒数 / 有效播放数 | 总观看时长、有效播放定义、单位 | 用视频时长代替观看时长 |
| 完播率 | 达到约定完成条件的播放数 / 有效播放数 | 完成条件（平台字段或观看比例）、播放 ID/汇总 | 没有完成条件不能由平均观看时长推算 |
| 互动率 | 互动次数或互动用户数 / 明确的曝光、触达或播放分母 | 点赞、评论、分享、收藏及统一分母 | 不把点赞率、评论率简单平均成互动率 |
| 分享/收藏率 | 分享或收藏次数（或用户数）/ 约定分母 | 对应事件、分母和去重规则 | 分享不等于新增触达或有效传播 |
| 净增关注 | 新关注数 - 取关数 | 账号 ID、关注/取关事件或平台净增字段 | 只有期末粉丝数不能推断自然增长 |
| 关注转化率 | 新关注用户数 / 触达或主页访问用户数 | 用户级事件、同一窗口、分母定义 | 没有触达或访问分母不能计算 |
| 外链点击率 | 外链点击数 / 曝光或触达分母 | 可追踪链接、点击事件、分母 | 点击不等于线索或购买 |
| 线索/订单转化率 | 归因线索或订单数 / 点击或触达用户数 | 线索/订单 ID、归因窗口、去重规则 | 没有归因规则不能把订单归给内容 |
| 内容归因收入 | 归因窗口内与内容接触有关的已确认收入 | 订单/支付 ID、接触事件、归因模型、退款口径 | 最后点击或平台“带货金额”不自动等于增量收入 |
| 平台结算收入 | 平台账单确认的结算金额，另列预估收入 | 结算账单、结算周期、扣费/退款规则 | 播放量乘行业单价不能生成收入 |
| 内容成本 | 可追溯到内容的制作、采买、投放等成本 | 成本科目、内容/项目归属、时间窗口 | 没有分摊规则不能估算单条内容成本 |
| 内容收入/成本效率 | 已确认或按模型归因的收入 / 内容成本；成本/收入另命名 | 同一归属粒度的成本、收入和归因窗口 | 相关收入不能写成内容带来的增量 |
| 粉丝留存/回访率 | 进入观察窗的关注用户在后续窗口仍活跃的比例 | 用户级关注时间、活跃事件、成熟观察窗 | 只有粉丝总数不能计算留存 |
| 创作产能 | 单位人日/周产出的有效内容数或时长 | 作者、投入工时、内容状态和窗口 | 发布量高不等于效率高或质量高 |

指标名称必须带平台、内容类型、时间窗口和分母。把“播放量”“互动量”“带货金额”直接当作质量、影响力或增量收益，会越过数据证据。

## 必须通过的数据门禁

1. **内容与账号 ID**：内容 ID、账号 ID 可稳定去重并能关联发布、曝光、互动和转化记录；跨平台 ID 不自动视为同一内容。
2. **事件时间与时区**：发布时间、曝光/播放、互动、关注、点击和订单使用事件发生时间；明确平台时区以及数据抓取延迟。
3. **指标定义版本**：记录平台对有效播放、触达、完播和互动的定义及版本；定义变更前后分段比较。
4. **重复与机器人**：去除重复抓取、回放、无效流量和测试账号；若平台已过滤，记录过滤规则而不是再次猜测。
5. **窗口成熟度**：内容发布后不同天龄不能直接比较；设定至少一个成熟观察窗，未成熟内容进入右删失区。
6. **归因与收入对账**：点击、线索、订单和结算收入必须有归因窗口、模型、退款处理和去重规则；平台汇总不能与订单明细重复相加。
7. **成本归属**：制作、达人采买、投放和人员成本的科目、归属粒度及分摊规则可追溯；否则不计算内容 ROI。
8. **隐私与小样本**：用户级数据满足脱敏和最小聚合阈值；小样本分组标记不稳定，不排名或下结论。

## 典型分析主题与流程

### 1. 内容分发趋势与异常定位

先锁定平台、账号、内容类型和内容天龄；按发布日或事件日报告发布量、触达、播放和互动，并与同星期或同天龄历史基线比较。把平台定义变化、投放流量和未成熟内容单独标记，不能把一次推荐波动直接写成内容质量变化。

### 2. 内容表现拆解与组合决策

按主题、形式、时长、作者、发布时段或流量来源拆解规模（触达/播放）、深度（观看时长/完播）和互动（评论/分享/收藏）。同时报告组内指标与内容数量，避免少量爆款的平均值掩盖整体分布；分组贡献只有在分子、分母和窗口可加总时才计算。

### 3. 观看与互动链路诊断

使用“曝光 → 有效播放/阅读 → 达到完成条件 → 互动 → 关注”的事件链，逐步核对分子、分母和用户去重。若只有平台汇总，输出各阶段量和平台报告的率，不声称用户级漏斗，也不把互动直接解释为长期留存。

### 4. 受众留存与内容组合

以首次关注、首次观看或首次订阅定义 cohort，计算后续活跃、回访和取消关注；同时看不同内容类型的受众迁移。没有用户级事件时降级为粉丝净增和活跃触达趋势；不能用粉丝总量的增长替代留存。

### 5. 内容到线索/订单的归因评估

先对齐点击、落地页、线索、支付和退款，再按用户或链接应用已确认的归因窗口。无随机对照时只报告“按该模型归因的收入/订单”及其不确定性；要回答增量效果，需保留未曝光对照、自然流量基线或实验分流。

### 6. 创作资源与商业化效率

把人力、制作、采买和投放成本与内容项目及结算收入对齐，报告单位内容成本、成本分布和按归因模型计算的效率。成本缺失或收入尚未结算时，只做产能、播放和点击的描述，不用行业单价补算收益。

## 行业叙事语言

- “该平台在内容发布后第 X 天的触达相对同天龄基线偏离 Y%”；
- “表现差异集中在某内容类型，规模差异和内容数量需同时考虑”；
- “完播与关注同步变化，是待验证的受众质量信号，不是因果结论”；
- “按当前归因模型记录了 X 元收入，不能据此确认增量收入”；
- “平台定义在某日期发生变化，因此前后指标只做分段比较”；
- “内容观察窗尚未完成，当前结果存在右删失”；
- “若补充用户级事件、成本归属和未曝光对照，可验证留存和增量转化”。

避免使用“爆款必然”“算法惩罚”“粉丝质量差”“内容带来了全部销售”等无法由当前字段闭合的判断。

## 图表优先级

1. 内容/账号指标趋势与同星期或同天龄基线；
2. 内容表现分布（箱线图或分位数）与内容数量；
3. 触达—完播—互动—关注的分母明确漏斗；
4. 主题/形式的规模 × 深度散点或分面图；
5. 关注或观看 cohort 留存热力图（仅用户级数据）；
6. 归因收入与成本瀑布/散点（明确模型和退款口径）；
7. 异常内容的帕累托或贡献条形图（分子分母可对账时）。

每张图写清平台、实体、窗口、内容天龄、分母、去重和归因规则；缺一项就降级为描述性图表或不绘制。

## 输出与降级

分析计划至少输出：`business_decision`、`metric_dictionary`、`platform_definition`、`event_time_policy`、`grain`、`attribution_window`、`evidence_contract`、`selected_methods`、`selected_charts`、`missing_data` 和 `max_claim_level`。

- 没有内容/账号 ID：只做原始平台汇总，不能去重或做内容贡献；
- 没有发布时间或事件时间：不做趋势、天龄比较和时效归因；
- 没有曝光/触达分母：不计算播放率、互动率或关注转化率；
- 没有用户级事件：不做用户留存、受众迁移和用户级漏斗；
- 没有归因窗口或订单 ID：只报告点击/订单共现，不计算内容归因收入；
- 没有成本与结算数据：不计算 ROI、利润或单条内容收益；
- 内容观察窗未结束：将未成熟内容排除出完整 cohort 和排名；
- 平台定义不一致：分平台报告，不能合并为一个总指标。

**最低可分析标准**：至少有内容 ID（或明确的内容汇总粒度）、账号/平台、事件或发布日期，以及一项平台观测量；这只能支持描述性趋势，不自动支持归因或因果结论。
