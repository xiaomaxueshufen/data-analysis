# 确定性算子目录

每个算子必须接受明确字段、过滤条件和基线，并在输出中写入 `evidence_id`、公式、样本和溯源。当前脚本实现的是通用基础算子，复杂方法可以继续扩展。

统一算子入口：

```bash
python scripts/da_ops.py <operator> --data <文件> --config <配置.json> --out <证据.json>
```

| 算子 | 用途 | 关键输入 |
|---|---|---|
| `profile` | 识别 sheet、表头、字段、类型、缺失和时间覆盖 | 文件路径 |
| `quality_gate` | 检查关键字段缺失、日期重复、空值与异常延迟 | profile、原始文件 |
| `baseline_dow` | 计算同星期稳健中位数与 MAD | 日期、指标、窗口 |
| `anomaly_scan` | 计算偏离、robust z、方向和候选日期 | 日期、指标、基线 |
| `funnel_rates` | 由阶段计数重算阶段率、损失量 | 阶段字段顺序 |
| `ratio_decomp` | 将分子/分母变化拆为量级与率变化 | 分子、分母、维度、基线 |
| `contribution` | 将总量缺口按组对账 | 组、当前值、基线值 |
| `ab_effect` | 效应、标准误、置信区间和基本显著性 | 分流、指标、实体 |
| `segment_profile` | 分层规模、价值、转化和覆盖 | 分层字段、指标 |

分母为 0、样本不足、日期不齐或基线不可用时返回结构化错误，不返回伪造数字。
